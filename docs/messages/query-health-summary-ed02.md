# Message: QueryHealthSummary

| Property | Value |
| --- | --- |
| **Type** | Message |
| **Message ID** | `ED02h` |

## Description

QueryHealthSummary is used to request a summary of the status of each Component that the Health Reporter is responsible for.  The health summary provides a list of (ComponentID, severityCode), in which a severity of zero represents operational status.
