# Messages and Events

This section contains documentation for all JAUS messages and internal events.

Use the sidebar navigation to browse messages, or use the search feature to find a specific message by name or ID.

## Message Documentation

Each message page includes:

- **Message ID** - Hexadecimal identifier
- **Description** - Purpose and usage of the message
- **Message Format** - Field-by-field specification including:
  - Field name and number
  - Data type
  - Units (where applicable)
  - Optional/required flag
  - Interpretation and enumeration values

## Message Types

- **Commands** - Messages that request an action
- **Queries** - Messages that request information
- **Reports** - Messages that provide information in response to queries
- **Events** - Notification messages for asynchronous updates
- **Internal Events** - Events used within service state machines
