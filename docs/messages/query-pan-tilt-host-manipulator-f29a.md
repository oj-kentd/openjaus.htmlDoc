# Message: QueryPanTiltHostManipulator

| Property | Value |
| --- | --- |
| **Type** | Message |
| **Message ID** | `F29Ah` |

## Description

This message is query the host for a manipulator, to support cases where a manipulator (or even a single actuator) is mounted on another.  The host is specified by a JAUS ID, as well as the joint number where joint one (1) is the first (base) joint.
