# Message: ReportDigitalResourceEndpoint

| Property | Value |
| --- | --- |
| **Type** | Message |
| **Message ID** | `F702h` |

## Description

Reports a list of known digital resource servers.  Each endpoint is represented by a URL; however, the URL shall not require a Domain Name Service (DNS) to resolve.
