# Message: QueryComponentMappings

| Property | Value |
| --- | --- |
| **Type** | Message |
| **Message ID** | `C530h` |

## Description

This message is used to query for the current mappings between components used in some sort of filtering, as reported by message C532 ReportComponentMappings.
