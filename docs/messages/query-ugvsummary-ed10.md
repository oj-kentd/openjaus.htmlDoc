# Message: QueryUGVSummary

| Property | Value |
| --- | --- |
| **Type** | Message |
| **Message ID** | `ED10h` |

## Description

This query requests a ReportUGVSummary message in response, allowing a client to request a summary report of health status.  The summary report is described in ReportHealthSummary.
