# Message: ConfirmRenderUselessRequest

| Property | Value |
| --- | --- |
| **Type** | Message |
| **Message ID** | `FFD8h` |

## Description

This message may be sent as a confirmation to a render-useless request.  Note that depending on the implementation of the render-useless action, this message may not be sent successfully.
