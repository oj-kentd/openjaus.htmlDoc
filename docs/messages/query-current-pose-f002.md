# Message: QueryCurrentPose

| Property | Value |
| --- | --- |
| **Type** | Message |
| **Message ID** | `F002h` |

## Description

Queries the pose that the Preset Pose service is currently in.  The pose will be either one of the valid unique integer IDs for a pose, or will be a transition from one pose to another.
