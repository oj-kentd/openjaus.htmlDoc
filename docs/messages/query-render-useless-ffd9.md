# Message: QueryRenderUseless

| Property | Value |
| --- | --- |
| **Type** | Message |
| **Message ID** | `FFD9h` |

## Description

This message is used to query if a target has been rendered inoperable.  Note that depending on the implementation of the render-useless action, the component may not respond.
