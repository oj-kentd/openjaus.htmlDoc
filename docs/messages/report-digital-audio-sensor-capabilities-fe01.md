# Message: ReportDigitalAudioSensorCapabilities

| Property | Value |
| --- | --- |
| **Type** | Message |
| **Message ID** | `FE01h` |

## Description

This message provides a report of encoded audio formats supported by the Sensor, including supported parameter ranges associated with each format.
