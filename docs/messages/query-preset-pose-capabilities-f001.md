# Message: QueryPresetPoseCapabilities

| Property | Value |
| --- | --- |
| **Type** | Message |
| **Message ID** | `F001h` |

## Description

Queries a list of poses that the Preset Pose service provides, plus the valid transitions between those poses.  Each pose must have a unique ID, and a unique name associated with it.  Each transition must be between two valid poses.
