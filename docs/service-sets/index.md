# Service Sets

JAUS services are organized into Service Sets based on their functionality. Each service set defines a cohesive group of related services.

## Available Service Sets

| Service Set | Version | Description |
|-------------|---------|-------------|
| [Core](/service-sets/core-v1-1) | 1.1 | Fundamental services (Discovery, Events, Access Control, etc.) |
| [Mobility](/service-sets/mobility-v1-0) | 1.0 | Vehicle control and navigation |
| [Manipulator](/service-sets/manipulator-v2-0) | 2.0 | Robotic arm and manipulator control |
| [Environment](/service-sets/environment-v1-0) | 1.0 | Environmental sensing and perception |
| [UGV](/service-sets/ugv-v1-0) | 1.0 | Unmanned Ground Vehicle specific services |
| [IOP](/service-sets/iop-v3) | 3 | Interoperability Profile services |
