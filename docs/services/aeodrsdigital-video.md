# AEODRSDigitalVideo

| Property | Value |
| --- | --- |
| **Version** | 1.4 |
| **URN** | `urn:jaus:jss:exp:aeodrs:AEODRSDigitalVideo` |

## Description

The AEODRS Digital Video Service extends the Digital Video Service by enabling a client to set the endpoint of a reqested video stream.  The AEODRS Digital Video Service Provides a means to set the video client endpoint to an arbitrary IP address and port; this capability allows a requestor to set up a video stream to be sent to a client other than itself.
