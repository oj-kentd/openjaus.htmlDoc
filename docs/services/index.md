# Services

This section contains documentation for all JAUS services. Services are organized by their parent service set.

Use the sidebar navigation to browse services, or use the search feature to find a specific service.

## Service Documentation

Each service page includes:

- **Service Identification** - URN, version, and description
- **Inheritance** - Parent services this service extends
- **Internal Events** - Events used within the service's state machine
- **Message Set** - Commands, queries, and responses the service handles
- **State Machine** - Visual diagram of service states and transitions
- **State Transitions** - Table of triggers, conditions, and actions
- **Actions** - Detailed action definitions
