# OpenJAUS Service Set Documentation

Welcome to the OpenJAUS Service Set reference documentation. This documentation covers the JAUS (Joint Architecture for Unmanned Systems) service definitions and message specifications.

## Service Sets

The documentation is organized into the following service sets:

- [Core Services](/service-sets/core-v1-1) - Fundamental services including Discovery, Events, Access Control, and more
- [Mobility Services](/service-sets/mobility-v1-0) - Vehicle control and navigation services
- [Manipulator Services](/service-sets/manipulator-v2-0) - Robotic arm and manipulator control
- [Environment Services](/service-sets/environment-v1-0) - Environmental sensing and perception
- [UGV Services](/service-sets/ugv-v1-0) - Unmanned Ground Vehicle specific services
- [IOP Services](/service-sets/iop-v3) - Interoperability Profile services

## About JAUS

JAUS (Joint Architecture for Unmanned Systems) is a component-based architecture for unmanned systems. It provides a standardized set of messages and services that enable interoperability between different unmanned systems and components.
